11. Accessibility notes

  • Never convey status by color alone — pair badges/dots with text labels.
  • #12B886 and #F5A623 on white: use ≥12px bold for large text; pair with labels for body text.
  • #E05C5C on white meets 4.5:1 for normal text.
  • Focus rings: use primary / accent tokens, not status colors.
  • Modal scrims: sufficient contrast; dialog content on --panel.
