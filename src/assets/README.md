# Design contract — Fuel by York IE

## Brand
- **Product:** Fuel — operating system for early-stage B2B growth (York IE).
- **Personality:** sharp · grounded · enabling (precise / modern / expert).
- **Accent:** mint `#12b886` on cool charcoal / cool-gray shells.

## Motifs (vector system)
1. Intelligence spark (XP / credits unlock)
2. Track rails (progress steps)
3. Partner mark (York)
4. Signal pulse (timeline)

**Register:** geometric monoline + restrained mint fills — diagrammatic, not playful mascot.
